# ==============================================================================
# Halcyon Birthdays List (~/.config/Halcyon/birthdays.txt)
# Add your family, friends, and colleagues' birthdays below.
#
# Supported formats:
#   MM-DD Name (BirthYear)   -> e.g. 10-25 Sarah (1998)
#   MM-DD Name               -> e.g. 04-14 Mom
#   YYYY-MM-DD Name          -> e.g. 1995-07-12 Alex
#
# Changes sync automatically into Halcyon Calendar (>calendar).
#
# No typing needed: export your contacts (contacts.google.com > Export > vCard),
# then press "Import Contacts" in the calendar. Halcyon finds contacts.vcf in
# ~/Downloads and fills in the block marked ">>> imported from contacts" below.
# Lines you type yourself stay untouched; importing again replaces only that block.
# ==============================================================================

# 12-28 Linus Torvalds (1969)
