# Halcyon features and settings

Moved out of the README. Back to the [README](../README.md).

## Themed apps
Everything follows the wallpaper colours (`scripts/app-themes.sh`, run by the island after every wallpaper change; `app-follow = off` in `~/.local/state/island` stops it):
- terminals, fish, Starship, btop, micro (transparent: no background of its own), Yazi, Spotify (spicetify), spotify-player, Discord (Vesktop), Thunar / Nautilus / Nemo / GTK file dialogs
- **VSCodium / Code - OSS / VS Code / Cursor**: a "Halcyon" colour theme (installed once as a tiny extension; after a wallpaper change use *Reload Window*)
- **Zed**: `~/.config/zed/themes/halcyon.json`, reloads live
- **Firefox / Zen / LibreWolf / Floorp**: toolbar, tabs, address bar, new tab page and about: pages (`userChrome.css` + `userContent.css`, the browser must have been started once and needs one restart). Chromium-based browsers cannot be themed from a file: they only get dark mode
- **Dolphin, Kate and other Qt apps**: a qt6ct palette and a Kvantum theme "Halcyon"

## Key features
- Minimal, rounded UI with smooth fast animations
- Quickshell "island" bar (see below) instead of waybar
- Wallpaper changes with a circular reveal from the screen centre (new wallpaper grows over the old one)
- Wallpaper is picked once per boot (stays the same across quickshell reloads); "Random wallpaper" in the drawer / panel changes it on demand
- Special workspaces that overlay the current one: SUPER+S scratch (SUPER+ALT+S sends the focused window there), SUPER+M music, CTRL+SHIFT+ESC system monitor, SUPER+D communication (your choice in Settings > Default apps > Chat: Vesktop, Discord, Telegram, WhatsApp Web ... or any website), SUPER+R is not a workspace any more: it opens the Halcyon calendar (Settings > Calendar). Music and communication start their apps from `scripts/special.sh` (see below)
- Mouse: hold SUPER and drag with the **right** button to move a window, with the **left** button to resize it (`kbMouseMove` / `kbMouseResize` in `variables.lua`, bound in `hyprland/keybinds.lua`; swap the two to get Hyprland's stock layout)
- Gestures: handled by Hyprland (`hyprland/gestures.lua`) and **editable in Settings > Touchpad gestures**: pick 3 or 4 fingers, then what each swipe (left / right / up / down) and pinch (in / out) does, from a list (workspaces, windows, island panels, lock / sleep, media, volume / brightness, open an app from the app menu, or any command). A gesture left on "Nothing" is not taken by Hyprland, so apps still get it. Defaults: 4 fingers left/right = next/previous workspace, 3 fingers up or down = toggle the scratch special workspace, 4 fingers down = sleep, 3-finger pinch = workspace tree.
- Mouse buttons: **Settings > Mouse buttons** lists the mice that are connected (touchpads left out) and lets you give the back, forward and middle buttons (and three extra buttons for gaming mice) an action, or "Move / Resize a window while held". Left and right click are never touched; a button left on "Default" still reaches the app. Both editors save to `~/.local/state/island/gestures.conf` (`scripts/input-conf.sh`, read by `hyprland/inputconf.lua`, `gestures.lua` and `mouse.lua`) and Hyprland reloads by itself The single-finger edge gestures come from the `touchpad-gestures` service: right edge up/down = volume up/down, top edge right/left = brightness up/down, left edge up/down = next/previous track
- Notifications: the island is the notification daemon (`quickshell/island/Notifs.qml`, `NotifCard.qml`, `NotifRow.qml`). **No bell button any more**: touch the **right edge** of the screen (upper part) and the notification centre slides out; leave it and it slides back (hover mode, see **Edge boxes** below). Swipe any notification (popup or in the centre) sideways and let go past half its width to dismiss it; the ✕ still works. Empty state is a tree-style node ("All caught up" / "Do not disturb"). A thin bar on that edge glows (and breathes) while something is unread, and goes grey while do-not-disturb is on. Keyboard: SUPER+SHIFT+N toggles it (closes by itself a few seconds after the pointer is off it), SUPER+SHIFT+D toggles do-not-disturb (also the DND chip in the panel), CTRL+ALT+C clears everything. **Popups** stack top-right, at most `notifMax` (5, top of `shell.qml`); a popup timing out only hides the popup, hover pauses the timer, click dismisses, right-click hides all popups, critical ones stay until dismissed. The centre keeps the latest `notifHistoryMax` (30). Apps in `coalesceApps` (`notify-send` by default) replace the earlier one with the same title, every other app only replaces an exact repeat. Click a row to run its action and remove it, `x` removes only it, `Clear` empties the list. No dunst/mako needed (only one daemon can own the D-Bus name, so stop it if it is running)
- **Quick terminal** (`quickshell/island/QuickTerm.qml`): touch the **top-left corner** (or SUPER+SHIFT+Enter, or `>quick terminal`) for a plain console box with a command line, so one-shot commands do not need a full terminal. While the input is empty and nothing has run it shows the **status of sysmode and the honeypot** as console lines (`>ids hit : 0`, `>alerts : 1 today · 3 total`, honeypot / ids / cowrie / decoy wifi, from `hx status`); the moment you start typing that fades away and your command and its streaming output take over. `sudo ...` and root sysmode actions ask for your password in the input line (masked, fed to `sudo -S`, never stored). The console takes the keyboard by itself a moment after it pops out (so you can type at once with a terminal open beside it) and keeps it while the pointer is over it; if another window opens, it lets go of the keyboard, and a click on it (or SUPER+SHIFT+Enter) takes it back. **SUPER+ALT+/** opens the list of every console command as a tree (`quickshell/island/CmdTree.qml`, same look as the SUPER+/ shortcuts tree; click a command to put it in the console, Esc closes), but only when sysmode is set up (`/usr/local/bin/sysmode` exists): without it the key is not bound and the shortcut is hidden in the shortcuts tree. `hotspot-on` / `hotspot-off` (scripts/hotspot.sh), `halcyon <command>`, `bar-builder`, `notification-builder`, `wallpaper-gallery` and `startup-view` work here too and Tab completes them, although the console runs bash and they are fish functions in a terminal. Enter runs, Up/Down history, Ctrl+C stops the command and everything it started, Ctrl+L or `clear` clears, Esc closes. While a command runs, its questions show even without a line end ("Proceed? [y/N]") and Enter sends your answer to it; a `sudo` inside a script or program asks in the password line too, `cd` is remembered. `secure` / `stealth` / `relaxed` / `lockdown` (or `sysmode ...`, or `sm ...`) switch sysmode (root actions use the in-console sudo prompt). vim / htop / ssh / less and friends open in a real `foot` window instead
- Performance page: CPU, RAM, TEMP and GPU rings. GPU shows "off" while the dGPU is asleep and never wakes it (`scripts/gpu.sh`, polled only while the page is open). Below the rings, a hardware card: processor (model, cores/threads), graphics (iGPU + dGPU names, read from sysfs + `pci.ids` so a sleeping dGPU is never woken), memory (size, type, speed and channels, e.g. `DDR5 · dual-channel`) and storage (drive model + used/total per mount, `scripts/disk.py`, refreshed while the page is open). RAM type/speed/channels come from `dmidecode`, which needs root: `install.sh` saves its output once to `~/.cache/island/dmi-memory.txt` (re-run it after changing RAM). Without that file you still get the size. Channels are inferred from the slot names, so treat them as a good guess
- **Startup & processes window** (`island/StartupWindow.qml`, data from `scripts/startup-view.py`): opens as its own full-screen overlay, the same way the wallpaper gallery and the bar builder do. Open it with `>startup` in the launcher, Settings > Startup & background > *Open the window*, or `quickshell ipc -p ~/.config/Halcyon/quickshell/island call island startup`. **Startup items** lists everything that starts with the desktop: Halcyon's own parts (Hyprland, the island, polkit agent, portal, clipboard watchers, gestures, tray applets, hypridle, power manager), your own `hl.exec_cmd("...")` lines in `hypr-user.lua`, systemd user services and autostart `.desktop` files, each with the processes it runs now, their memory (PSS, so shared libraries are not counted twice), CPU and process count. The switch changes what starts next login (and starts / stops it at once where that is safe: applets, clipboard, gestures, services); polkit and portal need a new login. **All processes** lists every process of yours (sort by memory or CPU), which startup item started it, and an End button (Hyprland, the island and systemd are protected). Tab switches view, F5 refreshes, Esc closes. It polls only while open (every 5 s) and drops its data when closed
- Cheatsheet: SUPER+/ (or `>shortcuts` in the launcher, or Settings > Shortcuts) opens a **tree** of every bind, gesture and `sysmode` command (`island/Cheatsheet.qml`, data in `island/Binds.js`). Type to search. **Click a shortcut to change it** (pick modifiers, click the key box, press the key, Enter or Save; Default / Turn off are there too) and use **+ Add a shortcut** under "Your shortcuts" for your own key -> command (type the command, or press *Pick an app instead of typing* and choose an installed app from the list: it fills in the command and the name). Changes go to `~/.local/state/island/binds.json` + `binds.lua`, which `hyprland/keybinds.lua` reads, and Hyprland is reloaded. If you add a bind to `keybinds.lua`, give it an id with `bind(id, keys, action)` and add the same id + default keys to `Binds.js`
- Extras: SUPER+ALT+T layout dwindle/scrolling (saved in `general.lua`), SUPER+ALT+N nightlight (`hyprsunset`), SUPER+PERIOD emoji picker (`bemoji`), SUPER+SHIFT+S frozen area screenshot (`wayfreeze`, `grim`, `slurp`; saved and copied), SUPER+CTRL+S screenshot panel (region / window / full screen, copy / save / both)

## Look & feel (design pass)
Goal: calm, clear, spacious, pleasant. Not stripped-down minimal: depth and texture are intentional.
- **One place to tune Hyprland's look**: the `LOOK` block in `variables.lua` (gaps, corner radius + squircle power, hairline borders, dim, blur, grain, shadow). `general.lua` and `decoration.lua` just read it
- **Depth**: soft wide shadows, frosted glass (blur + fine grain + a little vibrancy) behind the bar, panels, notifications and overlays, neutral 1px hairlines that suit any wallpaper, a faint top sheen on every surface (`island/Glass.qml`, `island/Shadow.qml`)
- **Tokens** live in `island/Pal.qml`: radii (`rSm`..`rXl`), a 4px spacing scale (`s1`..`s6`), a type scale (`tCap`..`tDisplay`), motion (`dFast/dMed/dSlow` + one signature curve). Change them there and everything follows
- **Type**: Inter for all text, the Nerd Font only for icons
- **Colour**: `scripts/palette.py` now makes low-saturation surfaces, a pastel accent and soft-white text (saturation capped), so colourful wallpapers stay gentle. `glass` / `glassBar` / `glassBarOpen` in `Pal.qml` set how see-through the surfaces are (bar 0.58 at rest, 0.74 when expanded, panel/cards 0.80-0.88). If you change them, keep each layer's `ignore_alpha` in `hyprland/rules.lua` below that opacity
- **Interface: New / Legacy / Classic** (Settings > Appearance > Look > Interface): `opt.uiStyle`, read as `Pal.zen` (New only) and `Pal.calm` (New and Legacy). New (the default): one soft pane with its single hairline and nothing outlined inside it; groups and cards are a faint fill (`Pal.group`, `Pal.box()`), fields a soft pill (`Pal.field`) that only rings while typing, the chosen option an accent wash with a lighter label (`Pal.chosenFill` / `chosenText`), the one main action of a window solid accent (`primary: true` on `Chip` / `ActionChip`), sentence-case captions (`Pal.cap()` keeps CPU, GPU, RAM ...), no header dots, quieter stars (`Pal.decor` 35 %) and, with Hide explanations (on by default), no explanations or "?" at all (`Hint`, `HelpTip`, Settings rows, Discover): ask > explains instead. Borders that the earlier styles draw read `Pal.bw` (0 in New). Legacy is the first calm look (a hairline around every box), Classic the original (sheen, accent outlines). Windows use `WinHeader` (leading actions, centred title, trailing actions, ✕ last; `Pal.centred` = New or Centred titles). Palette tokens must not start with `on` + capital: QML reads `onFill` as a signal handler and the colour comes out black.
- **Motion**: one easeOutQuint curve everywhere, no bounce. Hyprland: windows ease in from 90%, workspaces slide a short way while fading, special workspaces slide vertically. Speeds are in `hyprland/animations.lua` (100ms units; lower by 1 if it feels slow)

## Island (quickshell/island)
- Pill bar: workspace numbers (SUPER+N), icons for the special workspaces (scratch / music / performance, lit while open), time/day/date, cava visualizer while music plays, wifi/bt/battery (one round **combined status icon** by default, see below)
- **Combined status icon** (`island/StatusRing.qml`; Settings > Bar style > "Combined status icon", per bar style, on by default): Wi-Fi in the middle (a dot and three arcs, lit by the signal; a plug for a cable), the battery as a ring around it (horseshoe open at the bottom, fills clockwise, red when low, green while charging), and up to three dots under it that close the ring's gap, one per connected Bluetooth device (`btn` in `net.sh`; with Bluetooth = Always, dim dots show it is on). "Show battery percentage" puts the number next to it. Turn the switch off for the three separate icons
- Hold and drag the bar sideways (or scroll / two-finger swipe): drag left = performance page, drag right = media page
- Auto-hide: toggle in the bottom-right panel (Rice > Auto-hide) or `> auto-hide`. When on, the bar slides away and stops reserving space; touch the top edge of the screen to bring it back. With Settings > Edge boxes = **Click** nothing happens on a touch: **click** the top edge to bring the bar back (it hides again once the pointer has left it)
- **SUPER+TAB: live tree overview.** Laptop (hostname, your name + avatar) -> every workspace -> the windows on it, special workspaces (scratch / music / sysmon) included. Nodes drift gently and a pulse runs along each branch. Click a node to jump to it. **Drag a window (leaf) node: its branch is cut, and when it gets close to a workspace a tether reaches out and joins; let go while joined and the window moves there (special workspaces too, or the "+ New workspace" pill). Let go anywhere else and the leaf swings back and its branch regrows**; Esc cancels a drag. Snap distances: `reachR` / `connectR` at the top of the drag block in `Overview.qml` `S` (or the toggle top-right) switches compact / full-size special workspaces, `E` or a click on the laptop node edits your display name and avatar (saved in settings.json), Esc closes Every workspace and window node also shows its live CPU and memory use (`scripts/wsres.py`, polled only while the tree is open), and the header shows the total.
- Tap SUPER: the bar grows into one search bar
  - type to search apps (ranked by usage; clutter like qv4l2 / avahi / Qt tools is hidden, list is `hiddenPatterns` in `island/Launcher.qml`)
  - `.` lists every installed app A-Z (`.fire` filters that list)
  - `>` lists commands: random wallpaper, calculator, settings, power options, power mode, wifi/bt, lock/sleep/log out/restart/shut down
  - `=` is a calculator, e.g. `=2*(3+4)`, Enter copies the result
- Bottom-right corner: hover it for Wi-Fi, Bluetooth, volume, brightness, power mode, rice options and power/session buttons. The Wi-Fi and Bluetooth chips are on / off buttons (click = radio on / off); right-click one to open its drawn list for scanning and picking a network / paired device (Wi-Fi asks for a password when needed). While a network connects, the box shows **every step as it happens**: finding the network (signal, security, channel), joining it, authenticating, asking the router for an IP address (DHCP), then the IP, gateway and DNS you got, the router's ping and whether the internet is reachable; a failure says why (wrong password, out of range, no IP from the router, a sign-in page in the way). Settings > Notifications > Wi-Fi details switches the list off. `bash scripts/wifi-connect.sh --plain "My network"` prints the same steps in a terminal; the last run is kept in `$XDG_RUNTIME_DIR/halcyon-wifi-connect.log` (the password is never printed or logged). The Sound chip opens its list on click (pick an output or input device) and mutes on right-click. With Edge boxes = Click (or when a box was opened from a keybind / the Apps button), a click anywhere outside the utilities box or the background-apps box closes it. Needs `nmcli`, `bluetoothctl`, `pactl`; the lists come from `scripts/wifi.py`, `bt.py`, `audio.py`
- **Focus mode** (utilities box > FOCUS, or SUPER+ALT+F, `scripts/focus.sh`): an advanced do-not-disturb for studying or work. Pick 25 / 50 / 90 minutes (or Pomodoro: work, short break, work ... a long break after the last round) and press *Start focus*. While it runs: Do not disturb is on (urgent notifications and the break reminders still show, everything else waits in the notification centre), Caffeine is on (no dim / lock / sleep), and every window whose class is in the **block list** is closed the moment it opens (and the ones already open when the session starts). It is a normal close request, never a kill, so an app can still ask about unsaved work. The countdown shows in the bar next to the Caffeine icon; the card in the utilities box has Pause (lifts the block), +5 min, Skip / Done and Stop. When it ends, Do not disturb and Caffeine go back to what they were before (ones you switched on yourself stay on). Block list and options: Settings > Focus mode (click an open app to block it, pick any installed app from a searchable list (`AppPicker.qml`, the same apps as the launcher), or type its window class; `*` is a wildcard), stored in `~/.config/Halcyon/focus-apps.conf` and `focus.conf`. A tiny background process (`halcyon-focus.service`, a transient user unit) runs only while a session is on and listens to Hyprland's window events; it needs `python3`. CLI: `focus.sh start [min] [pomo]`, `stop`, `pause`, `resume`, `add N`, `skip`, `status`, `block CLASS [CLASS...]`, `unblock CLASS`
- Power mode: Auto / Saver / Balanced / Perf. **Auto is the `power-manager` daemon** (`custom/power-manager`, user service `power-manager.service`): battery vs AC, CPU/GPU load, heavy apps, idle, game mode and a thermal guard with hysteresis, plus 144/60 Hz switching. Picking Saver / Balanced / Perf by hand stops the daemon; Auto (or SUPER+ALT+P) starts it again. The performance page always shows the profile that is actually active, and in Auto it adds why (`· auto (on battery)`, `(heavy load)`, `(thermal hold)`, ...)
- Performance page also shows the active **sysmode** (`/etc/sysmode.mode`: secure / stealth / relaxed / lockdown, coloured like `sysmode status`). Read-only: change it with the `sysmode` CLI
- `./install.sh` builds `power-manager`, `touchpad-gestures` and `hx` (sources in `src/`), installs them to `~/.config/Halcyon/bin` with their user services, and installs the `sysmode` CLI (`sysmode/`) to `/usr/local/bin` (needs cargo, sudo for sysmode, and the `input` group). Nothing outside this folder is needed any more
- Settings (auto-hide, whether Auto power was on, compact specials, profile) are saved in `~/.local/state/island/settings.json`
- Colours follow the wallpaper (quickshell/island/scripts/palette.py, needs imagemagick)
- Needs Qt >= 6.6 (MultiEffect masks, curve renderer). Text font: first installed of Inter / Noto Sans / ... (`uiFonts` in `island/Pal.qml`; `pacman -S inter-font`)
- Deps: quickshell cava imagemagick networkmanager bluez-utils power-profiles-daemon brightnessctl wireplumber (wpctl) wl-clipboard playerctl-compatible MPRIS player

## Edge boxes: hover or click
The three edge boxes (notifications on the right edge, console top-left, utilities bottom-right) share one toggle: **Edge: Hover / Click** in Settings, `>edge boxes` in the launcher, or `quickshell ipc ... call island edgemode`.
- **hover**: touch the edge/corner to open, move away to close. Corner and box share one hover zone, so nothing flickers when the box slides in under a resting pointer.
- **click**: click the edge/corner (a faint tab marks it) to open, click it again to close; Esc closes the console too.
- **Auto-hide on**: in both modes every box closes as soon as the pointer leaves it (the console waits while you have text typed or a password prompt open).

## Settings (gear) and power button
The utilities panel is now: wifi / bluetooth / audio chips, sliders for **volume, microphone (click the icon to mute) and brightness**, power mode, and one row with **Settings**, **Gaming** and a round **power button**.
- **Settings** (`SUPER+I`, `>settings`): a centred window in the tree style: wallpaper, transparency, corner rounding, gaps, blur, shadows, island and window animations, auto-hide, do-not-disturb, edge mode, profile constellation, gaming mode, edit config, cheatsheet, reload Hyprland. Values are remembered in settings.json; the Hyprland ones are pushed with `hyprctl eval` and re-applied at island start (only once you have changed one, otherwise your Lua config rules).
- **Power button** (`>power options`): blurs everything and shows Lock / Sleep / Log out / Restart / Shut down in the middle of the screen (L S O R P keys, Esc cancels, destructive ones ask "Sure?").
- **Gaming mode** (`SUPER+F10`, `scripts/gamemode.sh on|off`): performance power profile (Auto power paused), Hyprland animations / blur / shadows / gaps / rounding off, island animations instant, visualizer off, and the helpers listed in `~/.config/Halcyon/gamemode.conf` stopped (default: cava, baloo, tracker). Off restores the profile, Auto power and reloads Hyprland. Sysmode / honeypot / IDS are never touched.
- The performance page no longer has the wifi / bluetooth chips (they live in the utilities panel).

## Flagship sysmode art
Constellations in the wallpaper accent colour (twinkling stars joined by hairlines, `ModeArt.qml`, layouts in `StarData.js`): `lockdown` is a shield, `stealth` a coiled dragon (original), behind the SUPER+TAB tree, the notification centre, the console, settings and the power menu. In any other mode the tree shows **your profile picture as a constellation** (`hx stars <image>`: stars land on the outline and bright features, each joined to its two nearest neighbours; switch it off in Settings).

## Slider lag
`hx ctl` replaces the 2-second `ctl.sh` poll: brightness is read from sysfs every 60 ms and volume is event-driven (`pactl subscribe`), so the utilities sliders follow touchpad gestures and media keys immediately.

## Lock screen (our own)
`quickshell/island/Lock.qml` is a real Wayland session lock (`ext-session-lock`) with PAM login (`island/pam/password.conf`, your own password): constellation backdrop (shield / dragon for lockdown / stealth, your profile picture otherwise), big clock, your picture and name, one password pill that shakes on a wrong password. Open it with SUPER+L, power menu > Lock, `>lock`, or `scripts/lock.sh` (falls back to hyprlock if the island is not running). For idle locking set hypridle's `lock_cmd = ~/.config/Halcyon/scripts/lock.sh`. If the island ever crashes while locked the screen stays locked by design (`loginctl unlock-session` from a TTY).

## Widgets on the lock screen
The same widgets can sit on the lock screen. In the Widget builder and in the desktop editor the **Desktop / Lock screen** switch picks which screen's list you work on (`opt.deskWidgets` or `opt.lockDeskWidgets`; `WidgetData.keyOf(target)`). `Lock.qml` draws the lock list with `DeskWidgets { target: "lock"; inert: true }`. What is allowed there: `WidgetData.lockBlocked` names the types that are left out (they run commands or show private things), `normalizeFor(d, "lock")` drops them from whatever is saved. How it is kept safe: the widgets get `lockEnv` from `shell.qml` (the live values, every action empty) and `WidgetHost` puts a click shield over each one (`WidgetData.lockButtons` lists the types that keep their buttons: only the music widget). `shell.qml` `lockBackLum` is the brightness of the lock background, so the readability colours fit it. Tests for the data helpers: `node tests/widgetdata-lock.test.js`.

## Profile constellation everywhere
In `secure` and `relaxed` (any mode that is not lockdown / stealth) the profile picture constellation (`hx stars`) now shows behind the tree, notification centre, console, settings, power menu and lock screen. `shell.qml` makes it once and hands it to every surface. Switch it off in Settings > profile constellation.

## Edge box sizes
The utilities panel and the notification centre share `boxW`, `boxPad`, `boxEdge` in `island/Pal.qml` (width 392, inner padding 18, 22px from the screen edge), so they always line up.

## Input fixes (utilities box, console, constellation)
- **Utilities box**: its panel and its hover zone are siblings, and chips / sliders take hover away from a sibling zone, so hovering a chip used to close the box 450 ms later. The panel now tracks its own hover too (`zoneHover` / `panelHover` in `shell.qml`).
- **Console**: the prompt and the output list swallowed clicks, so nothing asked Wayland for the keyboard. Clicking them now does, and in hover mode resting the pointer on the box for 250 ms is enough to type. Leaving with an empty prompt closes it and hands the keyboard back.
- **Gaming chip**: the island re-reads `/dev/shm/halcyon-gamemode` after each click (and every 5 s), so the chip always matches the script.
- **Constellation**: `scripts/avatar.sh` finds the picture (chosen path, `~/.face`, `~/.face.icon`, AccountsService, `~/.config/Halcyon/avatar.*`). With no picture, or one that gives almost no stars, a sky made from your name is shown instead (`Stars.fromName` in `StarData.js`).

## Timelines and the blurred lock screen
- **Timelines** (Settings): the Backup / Safety rail style also shows the last wallpaper change (Settings > Wallpaper), the last system update (Backup & safety, from `/var/log/pacman.log`; unknown without it) and your Focus streak against your best (Settings > Focus mode). They only read data that already exists; `python3 ~/.config/Halcyon/scripts/timeline.py status` prints the same in a terminal.
- **Blurred lock screen wallpaper** (Settings > Power & lock > Lock screen background): your wallpaper, blurred, behind the clock and the password box; Blur and Tint set how strong. Off by default. If the picture cannot be read you get the plain colour; the password box never changes. It is loaded only while locked and let go on unlock.

## Safe mode and Profiles
- **Safe mode** (`halcyon safe-mode`, Super + Alt + F12, or Settings > Performance): blur, shadows, window animations, stars and island motion off, island reloaded. `halcyon safe-mode back` (or the shortcut again) puts your values back. Works from a terminal or TTY even when the island is unusable: without fish run `python3 ~/.config/Halcyon/scripts/halcyon-fx.py safe-mode`.
- **Profiles** (Settings > Performance, or `halcyon profile work|gaming|battery|night|custom`): stars, blur, motion, brightness and the top bar in one switch. Custom is your own setup, saved when you leave it. Change a profile in `~/.local/state/island/profiles.json`; `halcyon profile list` shows the current values.


## Luna

`>luna` in the launcher, `halcyon luna` (or `quickshell ipc ... call island luna`). Your conversations with [Luna](https://github.com/X-netrunner/LUNA-AI), the local assistant (`./install.sh --luna`). Every chat is a saved session on the left: open an old one and carry on where it stopped, because Luna gets that conversation's own memory back. While she works you see which tools she runs and, with "Show the reasoning", what she thought. Rename or delete a chat with the pencil and bin that appear on hover.

- **Slash commands** (type `/`, Tab completes): `/model [name]` (the model picker, or switch to NAME), `/settings`, `/keys`, `/status` (Halcyon at a glance, read from the real firewall, antivirus and AI state), `/new`, `/clear`, `/test-model`, `/help`, `/exit`.
- **Settings** (the gear in the header): the chat list is replaced by pages (Models, Voice & audio, System & watchdog, Safety gates, Integrations, No-refusal mode, This window, API keys), one at a time. **Models** has one menu: *Auto* (Luna picks fast, main, deep or security for each question, the way she was designed) or a single model for everything. Under Auto, a menu per role lists what Ollama has installed. The other pages are the terminal UI's switches (thinking, native tools, voice, wake word, watchdog, proactive monitor, safety gates, integrations). **API keys**: *Paste key* next to Tavily, Gemini, Todoist or Spotify stores it in the system keyring. ## Brightness gesture (top edge)
The gesture runs `scripts/brightness.sh`, which tries `brightnessctl`, then a direct sysfs write, then logind, and prints why it failed in `journalctl --user -u touchpad-gestures -e`. The usual cause is not being in the `video` group (the service is outside your login session, so logind cannot vouch for it): `sudo usermod -aG video $USER`, log in again. The top strip is now 10 % of the pad (it was 4 %) and one slide step is 4 % of the pad width. Rebuild with `./install.sh` after pulling this change.

## sysmode stealth: why the honeypot / IDS did not start
Two causes, both fixed in `sysmode/sysmode`: (1) `start_cowrie` returns 1 when Docker is missing or its daemon is stopped, and `set -e` ended the whole stealth switch right there, before the recon-deceiver, the IDS and the MAC logger were launched (the mode file already said `stealth`, but the final "Mode changed to: STEALTH" line never appeared). It is now `start_cowrie || true`. (2) `SYS_USER` / `SYS_HOME` defaulted to a user called `netrunner`, so on any other account the scripts directory did not exist and the fallback hid the error behind `>/dev/null`. The user now comes from `/etc/sysmode.conf`, else sudo's caller, else the login user. The daemons start with `setsid nohup`, their output goes to `~/logs/<name>.out`, and a daemon that dies on start is reported with its last lines. After `./install.sh` run `sudo sysmode stealth` again; `sysmode status` should show the honeypot and IDS as Active.

## Idle dim, keyboard light, volume / brightness bar
- **Dim when idle** (Settings > Sleep & lock, default 3 min): the screen fades to its lowest brightness and the keyboard light goes off; any key or mouse move puts both back exactly as they were. `scripts/idle-dim.sh` (called by hypridle through `scripts/idle.sh`, which now writes a third listener). The saved levels live in `/dev/shm/halcyon-dim`, so a reboot can never leave you in the dark. Caffeine stops it like it stops lock and sleep.
- **Keyboard backlight**: `scripts/kbd-backlight.sh status | up | down | set PCT | toggle | doctor [--load]`, bound to XF86KbdBrightnessUp / Down / LightOnOff. `scripts/backlight.sh` writes screen and keyboard light with three fallbacks (brightnessctl, sysfs, logind). - **Volume / brightness / keyboard-light bar** (`Osd.qml`): slides up from the bottom edge on every change and goes away by itself, no matter what changed it (keys, touchpad edge gestures, the panel sliders, other apps). ## Login screen (greetd) and the two login choices

Two separate choices (asked once at install, again with `./install.sh --choose`; later in Settings > Power & lock):

| | Halcyon way | Other way |
|---|---|---|
| **At boot** (`--login-mode`, `opt.loginMode`) | `greeter`: **Halcyon login manager**, greetd + `greeter/shell.qml` (Quickshell in `cage`), no widgets | `lock`: auto-login on tty1 + the lock screen (hyprlock is only its fallback), widgets allowed |
| **After sleep / when locked** (`--lock-mode`, `opt.lockMode`) | `login`: the login-screen look, **no widgets** | `lock`: the full lock screen, widgets allowed |

**Widgets exist on the lock screen only.** The login manager and the login-screen look never show the Widget builder's widgets, the media card or the Switch-user button (the greeter has only the clock, the picture, the password and small switches: background, constellation, clock, seconds, battery, Wi-Fi name, power buttons, session name).

Boot choice: `./install.sh --login-mode greeter|lock` (or `--greeter`), or Settings > Login screen > *At boot* then **Apply** (opens a terminal, one sudo prompt). Undo: `./install.sh --remove-greeter`. The old display manager is only switched off. If the greeter ever breaks, Ctrl+Alt+F2 is a plain text login. Try it without logging out: `scripts/halcyon-greeter.sh preview` (type `preview` + Enter).

Look: the lock screen's twin. Same layout, fonts, sizes, colours and password pill, and the same constellation art (your picture as stars, the stealth / lockdown art, drifting and flying stars: Backdrop / ModeArt / BarStars are the island's own files, copied at install). The island writes its look to ~/.cache/island/greeter-look.json and the sync service copies it to the greeter. The background follows the lock screen's (Settings > Power & lock > Login screen background: same as lock / wallpaper / solid). No card, no greeting.

Switching: bottom left, **Switch user** opens the list of accounts (with their pictures) and the desktop chip lists every Wayland session (Halcyon, Hyprland, Plasma ...). Left / Right and Tab do the same from the keyboard. The picture is the one you chose in Halcyon.

Constellation: Settings > Lock screen has ONE switch for the constellation; it turns it on or off on the lock screen and the login screen together. (The faint shapes that shone as you typed are gone from both screens.)

After an update: the boot login screen runs the root-owned copy in `/usr/local/share/halcyon-greeter`, not this folder. `install.sh` (and so `update.sh`) now copies the new files there when the login manager is installed; `scripts/halcyon-greeter.sh refresh` does the same by hand, `status` says when the installed copy is out of date, and `doctor` checks greetd, cage, the greeter user, the config, the session file and prints greetd's journal for this boot.

Security model:
- The greeter runs as the unprivileged `greeter` user and never reads your home. Passwords go to greetd over its socket (PAM) and are not stored; the box is cleared before PAM asks, a conversation nobody answers is cancelled after 60 s, and wrong passwords slow down (greetd and `pam_faillock` apply their own limits too).
- **A file you can write never decides who logs in or what runs.** Users come from `getent`, sessions from root-owned `/usr/share/wayland-sessions`, both read by root-owned `users.sh` / `sessions.sh`. `theme.json` (yours) only decorates: colours, switches, and pictures that must live inside `/var/lib/halcyon-greeter`.
- Pictures are re-encoded (ImageMagick, when installed) before the greeter decodes them.
- Greeter files in `/usr/local/share/halcyon-greeter` are root-owned; `/etc/greetd/config.toml` is backed up and restored by `--remove-greeter`.
- `halcyon-greeter.sh status` shows whether `pam_faillock` is active.
- **"[libseat] could not connect to socket /run/seatd.sock" at login:** the session found no seat (no logind session from PAM and seatd not running). `scripts/halcyon-greeter.sh doctor` adds pam_systemd to greetd's PAM file if it is missing, installs and starts seatd, and puts you in the seat group. Install runs the same check.
