# Halcyon project map

Halcyon is a Linux desktop environment built around Hyprland and a single Quickshell “island” process. Arch is the reference platform; Debian, Fedora and NixOS are also supported. The README specifies Hyprland 0.56+ for the Lua configuration.

## Architecture and stack

- `hyprland.lua`, `variables.lua`, `hypr-user.lua`, `hyprland/`: compositor entry point, user overrides and modular Lua configuration. `scheme/` contains appearance configuration.
- `quickshell/island/shell.qml`: central Qt/QML and Quickshell UI, state and timers. Neighboring QML components implement the bar, launcher, settings, lock screen, notifications, widgets, games, study and security; `Pal.qml` holds visual/performance settings, and JavaScript modules provide shared UI logic. `quickshell/island/scripts/` supplies feature-specific glue.
- `src/`: Rust helpers. The root Cargo workspace contains 11 crates: `hx` (system feeds and utilities), `hal`, `hgl` (game launcher), `power-manager`, `touchpad-gestures`, `birthday-sync`, `safety-check`, and the sysmode helpers `recon-deceiver`, `log-analyst`, `attacker-dossier`, `setStaticMac`. The island consumes persistent `hx` feeds; shell scripts provide fallbacks. Python and shell scripts support on-demand features and system integration.
- `src/halcyon-music/`: separate Cargo workspace for a Spotify player. `halcyon-music-core` defines shared types and a versioned NDJSON Unix-socket protocol; `halcyon-musicd` owns playback, auth and cache; `halcyon-music` is an iced GUI client. See its README for dependencies and operation.
- `scripts/`, `sysmode/`, `systemd/`, `udev/`: system and feature scripts, optional security tooling, services/timers and hardware rules. `greeter/`, `launch/` and `plymouth/` handle session startup and login visuals.
- `install.sh`, `get.sh`, `update.sh`: installation/bootstrap, updates and rollback. `flake.nix` and `nix/` provide Nix integration; `config/` contains application defaults.
- User runtime state is primarily under `~/.local/state/island/` and `~/.local/state/halcyon/`; installed helpers live in `~/.config/Halcyon/bin`.

## Navigation and verification

- `README.md`, `docs/architecture.md`, `docs/how-it-works.md`, `docs/features.md` and `docs/games.md` explain behavior and design. `graphify-out/` contains generated project graph artifacts.
- Root Rust workspace: `cargo build --workspace` and `cargo test --workspace`; run music workspace commands from `src/halcyon-music/` separately. `tests/` includes Python, JavaScript and shell tests; music daemon integration tests are under its crate's `tests/`.
- `docs/architecture.md` describes CI checks, but `.github/workflows/` was absent in this checkout when this map was created. Check the current tree before relying on those workflow paths.

## Music investigation (2026-11-07, follow-up)

Live logs show librespot AP authentication and track loading succeeded. The Web API returned 429 on several endpoint families, including a 24-hour Retry-After. The GUI treated any cached playlist/liked result as offline, so it falsely showed Offline (cached) despite a connected daemon. GUI now labels this Cached library, avoids duplicate playlist requests on connect/sign-in, and the API applies a 429 cooldown globally. Music workspace tests pass. Source mirrored to Downloads shipout.

Release build passed and was installed to ~/.config/Halcyon/bin; the systemd user daemon was restarted and is active. Both installed binaries match the release build. Live Spotify audio after this update has not been manually exercised.
